# DecodeLabs Internship | Task 1: Data Cleaning and Preparation

## Project Overview

This project was completed as part of the **DecodeLabs Data Analytics Internship**.

The objective was to prepare an e-commerce orders dataset for analysis using Microsoft Power BI and Power Query, with an emphasis on data quality, consistency, and reliable data preparation.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- Microsoft Excel

## Project Workflow

1. Imported the e-commerce dataset into Power BI.
2. Inspected the dataset structure and column data types.
3. Examined data quality, including missing values and inconsistencies.
4. Applied data cleaning and transformation steps using Power Query.
5. Standardized relevant text fields and prepared columns for analysis.
6. Reviewed the transformed dataset before saving the final Power BI file.

## How to Review the Project

1. Download the Power BI `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Select **Home > Transform data** to inspect the Power Query transformations.
4. Read the PDF cleaning log for further details.

If the dataset connection needs updating, point the source to the downloaded Excel file.

## Project Outcome

The project demonstrates practical experience with data preparation, quality checking, and Power Query transformations, providing a foundation for subsequent exploratory analysis.
